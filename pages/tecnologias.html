Importancia de las tecnologias web

Las tecnologias web permiten crear paginas y aplicaciones que facilitan la comunicacion, el acceso a la informacion y el desarrollo de diferentes actividades en internet. Entre las principales se encuentran HTML, CSS y JavaScript.
